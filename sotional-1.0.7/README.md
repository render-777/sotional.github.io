# 소셔널 바둑 클럽 1.0.7

Docker Compose 기반의 바둑 클럽 웹앱입니다. 게시판, 일정, 레이팅, 리그전 순위표, 토너먼트 브래킷을 운영할 수 있습니다.

## 1.0.7 변경사항

- 토너먼트 우승자가 정해지면 결과 영역 표시
- 토너먼트 결과에 우승, 준우승, 3위, 4위 표시
- 로그인한 사용자가 직접 비밀번호를 변경할 수 있는 기능 추가
- 상단 계정 영역에 `비밀번호 변경` 버튼 추가

## 주요 기능

- 오늘의 방문자 수
- 공지사항, 자유게시판, 소셔널 리그, 소셔널 뉴스, 건의게시판
- 소셔널 일정 달력
- 사용자 레이팅
- 리그전 순위 자동 계산
- 4강, 8강, 16강 토너먼트 브래킷
- 팀전/대항전 표 양식
- 게시글 사진 업로드
- 계정 관리 및 비밀번호 변경

## 실행 방법

```bash
tar -xzf sotional-1.0.7.tar.gz
cd sotional-1.0.7
docker compose up -d --build
```

접속 주소:

```text
http://localhost:8080
```

내부망 다른 기기:

```text
http://192.168.0.103:8080
```

## 토너먼트 결과 표시

1. 토너먼트 게시글 상세 화면에서 각 경기 승자를 선택합니다.
2. `리그표 저장`을 누르면 승자가 다음 라운드로 올라갑니다.
3. 결승 승자까지 선택하면 오른쪽 결과 영역에 우승, 준우승, 3위, 4위가 표시됩니다.

## 비밀번호 변경

1. 로그인 후 우측 상단 `비밀번호 변경`을 누릅니다.
2. 현재 비밀번호와 새 비밀번호를 입력합니다.
3. 변경 후 새 비밀번호로 로그인할 수 있습니다.

## 운영 명령

```bash
docker compose logs -f
docker compose down
```
