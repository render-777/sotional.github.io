# 소셔널 바둑 클럽 1.0.9

Docker Compose 기반의 바둑 클럽 웹앱입니다. 게시판, 일정, 레이팅, 리그전 순위표, 토너먼트 브래킷을 운영할 수 있습니다.

## 1.0.9 변경사항

- 레이팅 탭 왼쪽 순위표에서 사용자 이름 클릭 가능
- 사용자별 레이팅 상세 화면 추가
- 상세 화면에서 승수, 패수, 승률, 현재 레이팅 표시
- 누구에게 이기고 졌는지 경기 히스토리 표시
- 히스토리에 일자, 결과, 상대, 승자, 패자, 레이팅 변동, 경기 후 레이팅, 메모 표시

## 주요 기능

- 오늘의 방문자 수
- 공지사항, 자유게시판, 소셔널 리그, 소셔널 뉴스, 건의게시판
- 소셔널 일정 달력
- 사용자 레이팅과 개인 히스토리
- 리그전 순위 자동 계산
- 4강, 8강, 16강 토너먼트 브래킷
- 팀전/대항전 표 양식
- 게시글 사진 업로드
- 계정 관리 및 비밀번호 변경

## 실행 방법

```bash
tar -xzf sotional-1.0.9.tar.gz
cd sotional-1.0.9
docker compose up -d --build
```

접속 주소:

```text
http://localhost:8080
```

내부망 다른 기기:

```text
http://192.168.0.103:8080
```

## 운영 명령

```bash
docker compose logs -f
docker compose down
```
