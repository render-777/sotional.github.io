# 소셔널 바둑 클럽 1.0.8

Docker Compose 기반의 바둑 클럽 웹앱입니다. 게시판, 일정, 레이팅, 리그전 순위표, 토너먼트 브래킷을 운영할 수 있습니다.

## 1.0.8 변경사항

- 레이팅 탭 순위표에서 `권한` 컬럼 제거
- 레이팅 1위, 2위, 3위 회원 이름 옆에 금/은/동 메달 형태 아이콘 표시
- 2026년 1월부터 5월까지의 레이팅 대국 데이터 169건 자동 반영
- 가져온 대국 데이터는 `레이팅 대국` 메모로 저장
- 대국 기록 표를 `순번`, `년도`, `월/일`, `승자`, `패자`, `메모` 형태로 표시
- 대국 데이터는 한 번만 반영되도록 `system_flags`에 가져오기 기록 저장

## 주요 기능

- 오늘의 방문자 수
- 공지사항, 자유게시판, 소셔널 리그, 소셔널 뉴스, 건의게시판
- 소셔널 일정 달력
- 사용자 레이팅
- 리그전 순위 자동 계산
- 4강, 8강, 16강 토너먼트 브래킷
- 팀전/대항전 표 양식
- 게시글 사진 업로드
- 계정 관리 및 비밀번호 변경

## 실행 방법

```bash
tar -xzf sotional-1.0.8.tar.gz
cd sotional-1.0.8
docker compose up -d --build
```

접속 주소:

```text
http://localhost:8080
```

내부망 다른 기기:

```text
http://192.168.0.103:8080
```

## 레이팅 데이터 반영

앱 시작 시 `sotional_rating_seed_2026_1_5_v1` 가져오기 기록이 없으면 제공된 대국 데이터를 자동 반영합니다. 이미 기록이 있으면 컨테이너를 재시작해도 중복 반영하지 않습니다.

## 운영 명령

```bash
docker compose logs -f
docker compose down
```
